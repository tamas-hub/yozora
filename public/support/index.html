YOZORA / SUPPORT

サポート

YOZORA 星空予報をご利用いただきありがとうございます。星空指数、月・惑星・流星群、ISSの見頃を、今夜の観測計画にまとめるアプリです。

よくある質問

位置情報を許可しなくても使えますか？

はい。都市選択から都道府県庁所在地を選べます。現在地は「現在地を使う」を押した場合にだけ取得します。

予報と実際の空が違います

星空指数は雲量・視程・月明かりから計算した目安です。標高、光害、地形、局地的な雲は含まれません。安全を確認し、現地の天気もあわせてご判断ください。

通信できないときは？

取得済みの直近予報がある場合は保存データを表示します。天体計算は端末内で継続しますが、新しい天気とISS軌道データの取得には通信が必要です。

不具合を報告したい

発生した画面、操作手順、iOSのバージョンを添えてGitHub Issuesへお知らせください。位置情報など公開したくない情報は記載しないでください。

不具合・ご要望を送る

English support

You can use YOZORA without granting location access by choosing a city. Forecasts are estimates based on clouds, visibility, and moonlight. If you need help, please open a GitHub issue with the screen, steps, and iOS version, but do not include private location information.
