# アプリ名重複チェック

実施日: 2026-08-14（日本ストア）

## 採用名

`YOZORA 星空予報`

親しみやすい既存名「YOZORA」を残しつつ、検索時に用途が伝わる「星空予報」を組み合わせた。App Store上の表示名と端末上の表示名を同一にしている。

## Apple Search API結果

| 検索語 | 検索結果件数 | 完全一致 |
|---|---:|---:|
| `YOZORA` | 0 | 0 |
| `YOZORA 星空予報` | 0 | 0 |
| `夜空マップ` | 28 | 0 |
| `ヨゾラ` | 160 | 0 |

検索URL例: `https://itunes.apple.com/search?term=YOZORA&country=jp&entity=software&limit=200`

「ヨゾラ」には別分野の「ヨゾラ｜発達グレーゾーンの子育てAI相談」があるが、名称・用途・表記のいずれも完全一致ではない。星空分野にはStellarium、Night Sky、Star Walk 2、星空ナビ等の競合があるため、説明文とスクリーンショットでは「今夜の星空指数」「ベスト時間」「全国比較」を中心に差別化する。

## App Store Connectでの確認

App Store Connectの新規アプリ作成時に `YOZORA 星空予報` が受理され、Apple ID `6801428026` のアプリ枠が作成された。Bundle IDは `jp.tama.yozora`。

## 注意

検索結果とApp Store Connectでの受理は、商標権の法的な非侵害を保証するものではない。今回はストア登録に必要な実務上の重複確認として実施した。
